# NetPay Admin — San Martín

Panel de administración de terminales NetPay (Vue 3 + Vite).

## Setup

```sh
npm install
```

Copia `.env.example` a `.env` y apunta al API:

```
VITE_API_URL=http://localhost:3017
```

## Desarrollo

```sh
npm run dev
```

## Credenciales semilla (API)
